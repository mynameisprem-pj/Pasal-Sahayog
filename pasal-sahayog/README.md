# Pasal Sahayog

**Simple stock management for every shop.**

Pasal Sahayog is a lightweight, offline-first stock management app designed for small shops and businesses. Track inventory, manage alerts, and keep your stock organized—all without worrying about internet connectivity.

## Features

✨ **Core Features**
- 📦 Add and manage items with categories
- 📊 Real-time stock tracking and inventory overview
- 🔔 Low stock alerts with customizable thresholds
- 🏪 Shop information management
- 📈 Visual stock overview with charts

🔒 **Data & Privacy**
- 💾 100% offline - all data stored locally on your device
- 🔐 No cloud sync or external servers
- 📤 Backup & restore - export and import your data anytime
- ⚙️ Full control over your information

📱 **Accessibility**
- 📲 Works on all devices (responsive design)
- 🌐 Install as a PWA - works offline and on homescreen
- ⚡ Fast and lightweight
- 🎨 Clean, intuitive interface

## Getting Started

### Installation
1. Open the app in your web browser
2. On mobile: tap the menu and select "Add to Home Screen" (or install the PWA)
3. Create your shop and start adding items

### Basic Usage
- **Dashboard**: View your shop overview and recent items
- **Stock**: Browse all items, filter by category, and manage quantities
- **Settings**: Configure preferences, backup data, and view app information

## Data Storage

**Important:** All your data is stored locally on your device. There is no cloud backup:
- If your device is lost, damaged, or reset, your data will be lost
- Regular backups are recommended using the built-in backup feature
- Any data loss is not the developer's responsibility

Always maintain regular backups of your important data.

## Browser Support

Works best on:
- Chrome/Chromium (Desktop & Mobile)
- Firefox (Desktop & Mobile)
- Safari (iOS 15+)
- Edge (Desktop)

## Development

This is a vanilla JavaScript PWA with no external dependencies.

**Tech Stack:**
- HTML5, CSS3, JavaScript (ES6+)
- Service Worker for offline functionality
- Local Storage API for data persistence
- Canvas for charts
